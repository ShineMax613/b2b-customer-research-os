# Contributing Guide

Thank you for your interest in contributing to B2B Customer Research OS.

This project is an open-source customer research and lead analysis system for B2B exporters, manufacturers, and international sales teams.

The goal is to help export sales teams research leads, qualify buyers, identify risk signals, and improve follow-up decisions before sending quotations, catalogs, or price lists.

## Who Can Contribute

You can contribute if you are:

- A B2B exporter
- A manufacturer
- An international sales professional
- A foreign trade salesperson
- A LinkedIn or WhatsApp sales operator
- A marketer working with overseas leads
- A founder or operator selling to global buyers
- A developer interested in building lightweight sales research tools

## What You Can Contribute

You can contribute:

- Customer research templates
- Lead qualification checklists
- WhatsApp follow-up message frameworks
- LinkedIn prospecting workflows
- AI prompts for customer research
- Anonymized real-world examples
- Lightweight tools for lead scoring or report generation
- Improvements to documentation and structure

## Contribution Principles

Please follow these principles:

1. Keep the content practical and useful for real B2B sales teams.
2. Do not include private customer data.
3. Do not include personal phone numbers, emails, screenshots, or confidential business details.
4. Do not make unfair assumptions about individuals or companies.
5. Use clear evidence when analyzing buyer intent or risk signals.
6. Keep templates easy to reuse and adapt.
7. Avoid spammy, aggressive, or misleading sales tactics.
8. Respect privacy, platform rules, and local regulations.

## How to Contribute

### Option 1: Open an Issue

If you have an idea, question, or improvement suggestion, open a GitHub Issue.

Useful issue examples:

- Suggest a new lead qualification checklist
- Report unclear wording in a template
- Request a new prompt for WhatsApp analysis
- Suggest an example for a specific industry
- Propose a lightweight lead scoring tool

### Option 2: Submit a Pull Request

If you want to add or improve content directly:

1. Fork this repository
2. Create a new branch
3. Add or edit the relevant file
4. Keep the content clear and structured
5. Submit a pull request with a short explanation

## File Naming Rules

Use lowercase letters and hyphens.

Good examples:

- buyer-intent-analysis.md
- company-background-check.md
- whatsapp-message-analysis-prompt.md
- lead-quality-scorecard.md

Avoid:

- Buyer Intent Analysis.md
- final-version-new.md
- template1.md

## Anonymized Example Rules

If you contribute real examples, they must be anonymized.

Do not include:

- Real customer names
- Phone numbers
- Personal emails
- Private WhatsApp screenshots
- Confidential quotation details
- Sensitive company information

You may include:

- Industry type
- Country or region
- General buyer type
- General inquiry message
- Lead analysis process
- Recommended follow-up strategy

## Suggested Example Format

Use this structure for real-world examples:

1. Lead source
2. Industry
3. Buyer type
4. Original inquiry summary
5. Available information
6. Missing information
7. Buyer intent analysis
8. Risk signals
9. Recommended next step
10. Suggested follow-up message

## Code Contributions

This project may include lightweight tools in the future, such as:

- Lead scoring calculator
- Customer research report generator
- CSV lead qualification template
- Prompt-based analysis helper

For code contributions:

- Keep tools simple
- Include clear usage instructions
- Avoid collecting private data
- Do not add unnecessary dependencies
- Prefer readable code over complex architecture

## Maintainer Notes

This project is maintained as a practical open-source resource for B2B export sales teams.

The focus is not only on templates, but also on building responsible AI-supported workflows for customer research, lead qualification, and sales follow-up.
